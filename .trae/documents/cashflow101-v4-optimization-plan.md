## 功能详细设计

### 功能1：游戏平衡性 — 失业概率调整

#### 问题
- 24格棋盘有1个裁员格（~4.17%概率），但失业持续2回合
- 实际影响：跳过2次发工资 + 支付2次支出，对低收入职业过于致命
- 慈善格目前只有"双骰奖励"，策略深度不足

#### 方案
**减少失业回合 + 增加慈善失业保护**

1. 失业回合从 2 减为 1
2. 捐赠慈善后获得"慈善保护"，下一次遭遇裁员时自动免疫
3. 保险（永久）和慈善保护（单次）同时存在时，优先消耗慈善保护

#### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/types/game.ts` | Player 接口增加 `charityProtection: boolean` |
| `src/stores/game.ts` | 失业回合改为1；acceptCharity 增加保护效果；layoff 触发时检查保护；状态补丁默认值 |
| `src/views/RatRaceView.vue` | 顶部状态栏增加"慈善保护"徽章显示 |

#### 关键改动点

- `player.unemploymentTurns = 2` → `1`
- 文案："跳过接下来 2 个回合的工资" → "跳过 1 个回合的工资"
- `acceptCharity` 函数增加 `player.charityProtection = true`
- `case 'layoff'` 中增加判断：`charityProtection` 为 true 时消耗保护并免疫
- `loadState` 补丁：`charityProtection ??= false`
- UI：`gameStore.currentPlayer?.charityProtection` 为 true 时显示 Shield/HeartHandshake 徽章

### 功能2：进入资本游戏弹窗（Bug修复）

#### 问题
- 完成原始资本积累（被动收入≥总支出）后，只有顶部栏一个小按钮"进入资本游戏"
- 移动端（sm以下）按钮完全隐藏（`hidden sm:inline-flex`）
- 用户不知道自己已经达标，可以进入快车道
- 需要强制弹出弹窗提醒用户

#### 方案
**满足条件时自动弹出进入资本游戏的确认弹窗**

1. 当玩家被动收入≥总支出时，自动弹出模态框
2. 弹窗展示：恭喜信息、当前财务数据、进入资本游戏按钮、暂不进入按钮
3. 移动端和桌面端都显示
4. 玩家可以选择稍后进入（关闭弹窗，继续在老鼠圈积累）

#### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/stores/game.ts` | 增加 `fastTrackOfferShown` 状态，避免重复弹窗；增加 `offerFastTrack` 方法 |
| `src/views/RatRaceView.vue` | 增加进入资本游戏模态框；被动收入达标时自动弹出；顶部按钮保留作为备用入口 |

#### 关键改动点

- 在 `recalcPlayerFinancials` 或 `handlePayday` 后检查是否达标且未弹窗
- 使用 `pendingAction` 或独立 ref 控制弹窗显示
- 弹窗内容：
  - 标题："恭喜！你已完成原始资本积累"
  - 描述：被动收入已超过总支出，可以进入资本游戏
  - 数据：当前被动收入 / 总支出 / 超额比例
  - 按钮："进入资本游戏" / "继续积累"
- 移除顶部按钮的 `hidden sm:` 类，确保移动端可见（或改为浮层按钮）

### 功能4：新手引导系统

#### 方案
**分步引导遮罩 + 事件触发型小贴士**

#### 4.1 分步引导（首次进入游戏时）

新建 `GameTutorial.vue` 组件，包含 8-10 个引导步骤：

| 步骤 | 目标 | 内容 |
|------|------|------|
| 1 | 全屏欢迎 | 欢迎来到 Cashflow 101，让我们了解游戏界面 |
| 2 | 顶部导航栏 | 游戏阶段、回合数、玩家信息、银行快捷操作 |
| 3 | 左侧财务面板 | 收入/支出/资产/负债，目标是被动收入 > 总支出 |
| 4 | 棋盘区域 | "原始资本积累"棋盘，掷骰子移动，触发不同事件 |
| 5 | 棋盘下方主按钮 | 点击"掷骰子"开始回合，之后变"结束回合" |
| 6 | 右侧机会卡 | 落在机会格时抽卡，可选择买入/卖出/放弃 |
| 7 | 底部浮层 | 显示当前待处理的事件和操作 |
| 8 | 开始游戏 | 准备好了吗？掷出你的第一骰！ |

技术实现：
- 半透明遮罩 + 镂空高亮（box-shadow 方案）
- 引导卡片（标题、描述、步骤指示器、上一步/下一步/跳过）
- 使用 `data-tutorial-id` 属性定位目标元素
- localStorage 记录是否完成引导

#### 4.2 事件触发型小贴士

首次触发关键事件时显示财商小贴士：

| 事件 | 贴士内容 |
|------|----------|
| 第一次机会卡 | 机会卡是积累资产的主要途径。关注现金流回报，而非只看价格。 |
| 第一次发工资 | 先支付自己——把收入的一部分先存起来或投资，再花剩下的。 |
| 第一次市场风云 | 市场有周期，低点买入高点卖出是投资的基本法则。 |
| 第一次失业/生活意外 | 紧急储备金很重要，至少保留 3-6 个月的支出。 |
| 第一次贷款 | 杠杆可以放大收益，也会放大风险。确保现金流能覆盖还款。 |
| 第一次做慈善 | 付出也是一种投资。善意和人脉会在意想不到的时候帮到你。 |
| 第一次购买房产 | 房产是经典的被动收入来源，但要注意首付和月供比例。 |
| 第一次购买股票 | 股票流动性强但波动大，不要用生活必需品的钱投资。 |

实现方式：
- game store 中维护 `seenTips: Set<string>`
- 事件触发时检查是否首次，是则设置 tip
- 在 pending panel 上方或独立的 tip 区域显示
- 用户点击"知道了"后标记为已见

| `src/types/game.ts` | 修改 | 增加 TutorialStep 接口、tip 相关类型 |
| `src/data/tutorial.ts` | 新增 | 引导步骤配置 + 财商小贴士数据 |
| `src/stores/game.ts` | 修改 | 增加教程状态、tip 状态、相关方法 |
| `src/components/GameTutorial.vue` | 新增 | 新手引导遮罩组件 |

- 决策效率：机会卡接受率 / 平均决策质量

## 假设与决策

1. **按钮位置**：主操作按钮保持在棋盘下方（用户已确认）
2. **失业平衡方案**：选择"减少回合 + 慈善保护"方案，而非单纯降低概率
3. **职业选择器**：使用卡片式选择器而非简单的下拉列表增强
4. **引导系统**：自建轻量组件，不引入第三方库
5. **引导持久化**：使用 localStorage 记录引导完成状态
6. **进入资本游戏弹窗**：自动弹出但允许"稍后进入"，不强制

## 版本控制

每个功能独立提交，commit 命名规范：

```
feat(balance): 失业平衡性调整 + 慈善保护机制
fix(fasttrack): 完成原始积累后自动弹出进入资本游戏确认
feat(setup): 职业选择器改为卡片式+难度筛选
feat(tutorial): 新手引导系统 + 事件触发小贴士
feat(education): 财商教育内容增强 + 总结分析优化
```

每个提交前确保：
- `npx vue-tsc --noEmit` 通过
- `npm run build` 通过
- 手动验证核心功能正常
