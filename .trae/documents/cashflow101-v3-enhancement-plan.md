# Cashflow 101 v3 增强版实施计划

## 概要

基于 v2 版本（股票增强 + 财务报表 + 图表 + Grid棋盘），新增 10 项功能：职业扩展与难度、职业详情展示、梦想选择、AI 对手、游戏引导教育、顶部操作栏、命名优化、随机历史故事、资产部分卖出、股票拆分/合股。

### 功能 10：股票数量限制优化

**目标**：股票不再固定只能买卖 1000 股，改为根据价格和资金动态计算。

#### 改动

1. **机会卡 maxQuantity 调整**
   - 低价股（$5-10）：maxQuantity = 5000
   - 中价股（$10-30）：maxQuantity = 2000
   - 高价股（$30+）：maxQuantity = 1000
   - 实际可买数量 = min(maxQuantity, 现金 ÷ 单价)

2. **`StockQuantitySelector` 组件**
   - 已实现动态计算（基于 available-cash 和 unit-price）
   - 确保最大值 = min(卡片上限, 资金上限)

3. **卖出机会卡**
   - 卖出上限 = 持有数量
   - 数量选择器已支持

### 功能 11：股票拆分/合股

**目标**：小机会卡增加股票拆分（1分2、1分4）和合股（2合1、4合1）类型。

#### 类型扩展

`src/types/game.ts` 中 `OpportunityCard` 增加 `splitRatio` 字段：
```typescript
interface OpportunityCard {
  // ... 现有字段
  splitRatio?: number  // 拆分比例：2=1拆2, 4=1拆4, 0.5=2合1, 0.25=4合1
}
```

或新增独立的卡片子类型。

#### 具体设计

**拆分类卡片（小机会）**：
- 标题："[股票代码] 宣布 1 拆 2"
- 描述："公司股价过高，宣布股票拆分。你持有的股票数量翻倍，价格减半。"
- 效果：持有数量 × 2，单价 ÷ 2（总市值不变）
- 类型：自动生效（不需要买入/卖出操作）

**合股类卡片（小机会/市场风云）**：
- 标题："[股票代码] 进行 2 合 1 合股"
- 描述："公司股价过低，为维持上市地位进行合股。你持有的股票数量减半，价格翻倍。"
- 效果：持有数量 ÷ 2，单价 × 2（总市值不变）
- 类型：自动生效

#### 卡片数量

新增 8 张拆分/合股卡（每只股票各 1 拆 2 + 2 合 1 各一张，共 5×2 = 10 张，但从中选 8 张）。

#### 实现方式

- 在 `applyOpportunityCard` / 市场事件处理中增加拆分/合股逻辑
- 修改玩家持仓的 `quantity` 和 `cost`（成本单价也相应调整，保持总成本不变）
- 更新 `marketPrice`（按比例调整）
- 记录交易记录

- A2. 职业扩展到 50 个 + 难度标签
- A3. 梦想扩展到 15 个 + 分类 + 故事

### 阶段 B：核心玩法扩展（中风险）
- B1. 股票拆分/合股功能
- B2. 股票数量限制优化
- B3. 房产/商业部分卖出
- B4. 随机历史故事卡

### 阶段 C：UI/体验优化（低-中风险）
- C1. 命名优化（老鼠圈→原始资本积累，快车道→资本游戏）
- C2. 银行/结束回合移到顶部
- C3. 职业详情展示
- C4. 梦想选择 + 梦想卡片

### 阶段 D：高级功能（高风险）
- D1. AI 人机对战
- D2. 游戏引导 + 财商教育

## 四、假设与决策

1. **AI 难度**：实现 3 级难度（简单/中等/困难），基于规则的决策系统，不使用机器学习
2. **职业扩展**：新增职业的支出数据基于工资比例推算，确保财务模型合理
3. **历史故事卡**：效果以现金增减为主，避免过度复杂的机制
4. **股票拆分**：成本 basis 按比例调整，不影响已实现的盈亏计算
5. **引导系统**：可跳过，不强制玩家观看
6. **顶部操作栏**：移动端和桌面端布局不同，移动端更紧凑
