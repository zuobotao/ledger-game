## 1. Current Architecture Map（要点）

### 状态权威
- **客户端权威**：Pinia `useGameStore`（`src/stores/game.ts`），持有关键响应式状态（phase / turnNumber / gameMonth / pendingAction / players / currentPlayerIndex 等）。
- **服务端权威**：`server/game/GameSession.ts` 持有一个 headless Pinia store（`server/game/headlessStore.ts` → `createGameHost`），通过 `actionMap.applyGameAction()` 执行协议 action，产出 snapshot / event log / replay。
- **Room 不保存 GameState**：`server/room/Room.ts` 仅管生命周期与玩家元数据，指向 `gameSessionId`。

### Turn / Round / Time / Age
- **Turn 推进**：store action `moveToNextPlayer()`（`src/stores/game.ts:801-872`）；`turnNumber` 每满一圈 `+= 1`。服务端经 `actionMap` 的 `end_turn` 调用同一 store。
- **Round**：**未找到独立 Round 推进器**；当前最小推进单位是 Turn / turnNumber（多人按玩家数轮转后 turnNumber+1）。多人下时间流速是否随玩家数变化，需在 Phase 1 验证。
- **Time / Age**：`gameMonth`（全局游戏月）在 `handlePayday` / fastTrack cashflow 格推进；`player.ageMonths` 为玩家年龄字段，由 `calcPlayerAge()`/`advanceMonth()`（`src/engine/turnEngine.ts`）计算。**当前未发现 gameMonth 与 player.ageMonths 的自动同步链路** —— 与用户反馈「回合 122 岁仍 28」相关的嫌疑点，正对 Phase 1。

### 共享度
- Single Player 与 Multiplayer **共享** store 实现（服务端每种会话独立创建同一 store 实例）与 engine 纯函数（turnEngine / financialEngine / loanEngine / assetEngine 等）。
- **Capital Game 无独立 engine**：Fast Track 规则实现为 store 内 phase 分支（`fastTrackRollDice` / `fastTrackBuyStock` / `fastTrackSellStock`）。
