| 能力 | 现状 | 结论 |

| `Asset.marketPrice` | 已存在（现价，缺省回落 `cost`） | ✅ 当前价格 |
| `Asset.loanAmount` / `monthlyLoanPayment` | 已存在（房贷/企业贷） | ✅ 贷款与月供 |
| `Asset.cashFlow` | 已存在（月现金流） | ✅ |
| `Asset.quantity` | 已存在 | ✅ |
| `Player.savings` | 已存在 | ✅ |
| `Player.childrenCount` / `lastChildTurn` | 已存在（含 v2.2 的 `MIN_TURNS_BETWEEN_CHILD_EVENTS`） | ✅ |
| 资产价值计算 | `calcAssetValue=(marketPrice??cost)*quantity` | ✅ 盈亏/收益率可由此派生，**不需新字段** |

### 派生公式（Phase 3 直接使用，不加字段）
- 买入均价 = `cost`（股票）
- 当前价值 = `calcAssetValue` = `(marketPrice??cost) * quantity`
- 成本（总） = `cost * quantity`
- 未实现盈亏 = `(marketPrice - cost) * quantity`
- 收益率 = `(marketPrice - cost) / cost`
