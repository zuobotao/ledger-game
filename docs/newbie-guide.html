Ledger 新手简介

一款教你看懂钱、模拟走向财富自由的桌游 App —— 玩几分钟你就明白「现金流」是怎么回事

本页为游戏《Ledger》的新手引导与概念简介，全部内容为教育模拟，不构成任何投资建议。

一句话：游戏里你要做的是——靠「买东西」攒出够多的被动收入，付得起每个月的生活开销，然后彻底不靠工资生活。

1先把 3 个词搞懂，你就不再迷茫

💸 收入 vs 支出

你一个月赚多少钱（收入）、花多少（支出），每月净剩 = 现金流。

👷 工资 = 主动收入，一把你停下来或失业，就没了。

📦 资产 vs 负债

让你钱越来越多的是资产；让你钱往外流的是负债。

🏠 收租的房子 = 资产  ·  🚗 每月还贷的车 = 负债

🐔 被动收入

「不用干活也进账」的钱，来自你买的资产。这是你要赢的目标。

买下现金流转正的资产 → 被动收入上涨 → 财富自由

2怎么算赢？

一步步升级，目标看得见：

老鼠赛跑开局在圈里打转攒资产 → 被动收入 ≥ 总支出财务自由，跳出圈 → 快车道高速积累，实现你的梦想（比如环游世界、买小岛）

3一局怎么玩？5 步上手

  1. 选职业选一个角色：工程师、医生、兽医… 不同职业薪水高、开销也高，难度不同。
  2. 选梦想选一个你「这辈子最想干的事」，那是你要攒到的东西。
  3. 掷骰子走格棋盘一圈圈走，落到不同格子触发不同事情。
  4. 碰到机会就判断买不买用现金「首付」买资产，让它给你持续带来现金流。这才是你翻身的核心动作。
  5. 盯住报表右下角资产负债报表是你的体检报告——现金、现金流、净资产，全在这里。

5给新手的 3 句话

  • 别只看「存款」。每月净剩多少（现金流）才是关键，那才是你持续买资产的本钱。
  • 优先买「现金流转正」的机会——花点首付、换一份长期被动收入，通常是划算的。
  • 别把现金烧光去硬买。留点儿应急钱，否则碰到裁员/意外就破产了。
Ledger 是一款财商教育模拟游戏：它想告诉你「让钱为你工作」才能走向财务自由。现实中那些宣称「躺着暴富」的高息借贷、赌博投机，恰恰相反——它们是让你的钱往外流的负资产。请理性看待游戏与现实。
