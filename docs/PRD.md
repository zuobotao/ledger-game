## 1. 项目背景与目标

### 1.1 背景

Ledger 是一款开源的财商教育模拟游戏，旨在通过互动式棋盘游戏帮助玩家理解个人理财的基本概念——包括资产与负债的区别、现金流的重要性、被动收入的积累以及财务决策的长期影响。

项目名称 "Ledger" 取自会计领域的通用术语"分类账"，象征着财务记录与理性决策的核心价值。

### 1.2 目标

- 提供一个可本地多人（热座）游玩的网页版财商教育游戏。
- 通过两个核心阶段（基础积累阶段与加速成长阶段）展示财务成长的路径。
- 通过财务报表、机会卡片、市场事件等机制，帮助玩家理解资产、负债、现金流的关系。
- 作为完全开源的教育项目，鼓励社区贡献和持续改进。

### 1.3 项目定位

- **性质：** 非商业开源教育项目
- **许可：** Apache License 2.0
- **免责：** 游戏内容均为虚构模拟，不构成任何投资建议

## 3. 术语表

| 术语 | 说明 |
|------|------|
| 基础积累阶段 | 游戏第一阶段，玩家通过工作、投资积累被动收入，目标是被动收入 ≥ 总支出 |
| 加速成长阶段 | 玩家跳出基础积累后的第二阶段，通过大额投资实现购买梦想 |
| 现金流 | 月收入 - 月支出 |
| 被动收入 | 来自资产（房产、股票、企业等）的收入 |
| 意外支出 | 非必要消费/意外开支 |
| 市场事件 | 影响资产价格或经济环境的事件 |
| 财务自由 | 被动收入 ≥ 总支出的状态 |

## 4. 核心游戏规则

### 4.1 胜利条件

- **基础积累阶段**：玩家月被动收入 ≥ 月总支出时，可跳出基础积累，进入加速成长阶段。
- **加速成长阶段**：玩家在加速成长赛道上购买自己的梦想（Dream），即获得游戏胜利。

### 4.2 回合流程

1. 掷骰子前进相应格数。
2. 根据落到的格子触发对应事件：
   - **机会（绿色）**：抽取小机会/大机会卡片（股票、房产、企业等）。
   - **意外支出（红色）**：随机产生非必要消费支出。
   - **发工资（黄色）**：获得月工资 + 当月现金流。
   - **市场事件（蓝色）**：影响所有玩家持有的资产价格或交易条件。
   - **家庭（青色）**：增加每月子女支出。
   - **慈善（金色）**：可选择捐赠 10% 总收入，下回合掷双骰。
   - **失业（紫色）**：失去工作，停止获得工资，可用保险抵消。
3. 玩家可选择在回合中贷款、还贷、交易资产。
4. 结束回合，轮到下一位玩家。

### 4.3 财务模型

- 每月现金流 = 总收入（工资 + 被动收入） - 总支出。
- 工资由职业卡决定。
- 支出包含：税金、房贷、学生贷款、车贷、信用卡、其他支出、子女支出。
- 玩家现金 = 储蓄 + 现金流累积 + 资产买卖所得 - 支出 - 投资本金。

### 4.4 贷款规则

- 玩家可向银行申请贷款，贷款额度通常为总收入的 10 倍或固定上限。
- 贷款增加每月还款支出（利息 + 本金）。
- 可随时提前还贷。

### 4.5 可选规则

- **保险**：避免失业事件影响。
- **大家庭**：提高孩子数量上限。
- **抵押贷款**：使用更真实的月供计算。
- **速开**：起始储蓄 = 总收入，加快开局节奏。

## 5. 功能需求

### 5.1 首页（Home）
- FR-001：展示游戏名称、简介、开始游戏按钮。
- FR-002：提供游戏规则入口（跳转至规则页）。
- FR-003：点击"开始游戏"进入游戏设置页。
- FR-003a：页脚显示法律链接（服务条款、隐私政策、免责声明）。
- FR-003b：显示版本号及开源许可标识。

### 5.2 游戏设置（Setup）
- FR-004：支持选择玩家人数（1-6 人）。
- FR-005：为每位玩家配置姓名、职业、颜色。
- FR-006：支持随机职业与随机颜色。
- FR-007：提供可选规则开关（保险、大家庭、抵押贷款、速开）。
- FR-008：校验至少 1 位有效玩家后进入游戏。

### 5.3 基础积累棋盘（Rat Race）
- FR-009：显示 24 格环形棋盘，含机会、意外支出、发工资、市场事件、家庭、慈善、失业等格子。
- FR-010：左侧显示当前玩家财务报表（收入、支出、现金流、储蓄、资产、负债）。
- FR-011：顶部显示当前玩家标识与"进入加速赛道"按钮（仅在满足条件时可用）。
- FR-012：底部提供"掷骰子"、"贷款"、"结束回合"操作。
- FR-013：玩家落点通过颜色棋子/token 标识。
- FR-014：根据落点格子触发对应事件。

### 5.4 机会卡片（Card）
- FR-015：抽到机会时弹出卡片详情。
- FR-016：卡片类型包括：股票、房地产、企业、其它投资。
- FR-017：玩家可选择买入、卖出或放弃。
- FR-018：交易后实时更新财务报表与现金。
- FR-018a：AI 学习模式下显示模拟分析（明确标识为游戏内分析，不构成投资建议）。

### 5.5 加速成长赛道（Fast Track）
- FR-019：显示加速成长线性轨道，含现金流日、机会、投资、意外支出、梦想等格子。
- FR-020：保留顶部玩家信息与返回按钮。
- FR-021：在梦想格显示当前玩家选择的梦想与价格。
- FR-022：玩家现金达到梦想价格时可购买并获胜。

### 5.6 游戏规则页（Rules）
- FR-026：左侧 Tab 导航（游戏简介、基础积累、加速成长、卡牌类型）。
- FR-027：右侧内容区以折叠面板展示详细规则说明。
- FR-028：支持返回首页导航。
- FR-029：响应式布局，移动端 Tab 转为顶部横排。

### 5.7 胜利结算页（Victory）
- FR-030：展示获胜玩家信息与庆祝动效。
- FR-031：显示关键数据概览（游戏回合数、最终现金、被动收入、总资产价值）。
- FR-032：展示成就徽章。
- FR-033：提供"再来一局"和"返回首页"操作入口。

### 5.8 银行操作弹窗（Bank Modal）
- FR-034：多 Tab 模式：存款、贷款、还款、资产。
- FR-035：存款 Tab：显示当前余额，支持金额输入与快捷按钮。
- FR-036：贷款 Tab：显示贷款总额，支持金额输入与快捷按钮，月息与月还款额计算。
- FR-037：还款 Tab：显示未还贷款与还款进度，支持金额输入与快捷按钮。
- FR-038：资产 Tab：分类显示股票、房产、企业，展示成本、市值、月现金流。
- FR-039：操作后实时更新玩家财务数据。

### 5.9 法律页面
- FR-050：服务条款页面（/terms）。
- FR-051：隐私政策页面（/privacy）。
- FR-052：免责声明页面（/disclaimer）。
- FR-053：关于项目页面（/about），含独立项目声明。

### 5.10 通用功能
- FR-023：游戏状态本地持久化（localStorage/IndexedDB），支持断点续玩。
- FR-024：提供"重新开始"和"回到首页"入口。
- FR-025：响应式布局，适配桌面与平板。
- FR-025a：全站页脚包含法律链接与版权声明。

## 7. 数据模型

### 7.1 玩家（Player）
```ts
interface Player {
  id: string;
  name: string;
  color: string;
  career: Career;
  // 财务
  salary: number;
  passiveIncome: number;
  totalIncome: number;
  expenses: Expenses;
  totalExpenses: number;
  cashFlow: number;
  cash: number;
  // 资产与负债
  assets: Asset[];
  liabilities: Liability[];
  // 棋盘位置
  ratRacePosition: number;
  fastTrackPosition: number;
  // 状态
  isUnemployed: boolean;
  hasInsurance: boolean;
  childrenCount: number;
}
```

### 7.2 职业卡（Career）
```ts
interface Career {
  id: string;
  name: string;
  salary: number;
  expenses: Expenses;
  startingCash: number;
}
```

### 7.3 机会卡（OpportunityCard）
```ts
interface OpportunityCard {
  id: string;
  type: 'small' | 'big' | 'stock' | 'real_estate' | 'business';
  title: string;
  description: string;
  cost: number;
  cashFlow: number;
  // 股票特有（虚构股票代码与公司）
  symbol?: string;
  priceRange?: [number, number];
}
```

### 7.4 游戏状态（GameState）
```ts
interface GameState {
  players: Player[];
  currentPlayerIndex: number;
  phase: 'rat_race' | 'fast_track';
  config: GameConfig;
  deck: Deck;
  marketEvents: MarketEvent[];
}
```

## 10. v1.5 游戏逻辑迭代回顾

### 10.1 失业规则优化（FR-039）
- 失业期间玩家可正常掷骰子移动，触发各种格子事件。
- 经过发工资格时，仅扣除支出，不获得工资。
- 失业持续 2 回合后自动恢复工作。
- 顶部玩家信息栏显示"失业中"徽章及剩余回合数。

### 10.2 市场事件多玩家支持（FR-040）
- 市场事件触发时，所有玩家的相关资产市值同步更新。
- 升值事件采用轮询式状态机。
- 市场面板显示当前操作玩家、进度。

### 10.3 慈善双骰视觉反馈（FR-041）
- 顶栏徽章显示"下次双骰"图标徽章，带呼吸动画。
- 双骰状态下，掷骰子按钮文字改为"掷双骰"。

### 10.4 骰子动画效果（FR-042）
- CSS 绘制 1-6 点经典骰子面。
- 点击掷骰后，全屏叠加层显示骰子翻滚动画。

### 10.5 正方形棋盘（FR-043）
- 24 格环绕正方形四边。
- 棋盘中心信息区显示当前玩家信息。

### 10.6 资产卖出机制优化（FR-044）
- 数量选择器：股票类资产卖出时支持 +/- 选择数量。
- 银行资产 Tab：分类显示股票、房产、企业。

## 12. 测试计划

- 多玩家热座切换是否正常。

- 法律页面内容完整性。

## 14. 风险与假设

- 假设玩家在本地同一设备上轮流操作，无需网络对战。
- 卡片与职业数据为静态配置，后续可扩展为动态加载。
- 原型阶段已确定视觉风格，开发阶段需保持与原型一致。
- "Ledger"名称存在一定商标风险，通过差异化定位和独立声明进行管理。
- AI 功能存在被误解为投资建议的风险，通过多层免责声明进行管理。
