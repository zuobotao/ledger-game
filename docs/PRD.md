## 1. 项目背景与目标

### 1.1 背景

Ledger 是一款独立开发的财商教育模拟游戏，旨在通过交互式游戏体验帮助玩家理解个人财务管理、资产配置和投资决策的基本原理。

游戏以"原始资本积累 → 财务自由 → 实现梦想"为主线，让玩家在模拟环境中练习职业收入管理、资产配置、风险控制等财商技能。

### 1.2 目标

- 提供一个可本地多人（热座）游玩的网页版财商教育模拟游戏。
- 包含两个核心游戏阶段：原始积累阶段和资本加速阶段。
- 通过财务报表、机会卡片、市场事件等机制，帮助玩家理解资产、负债、被动收入的关系。
- 以纯娱乐和教育为目的，不构成任何投资建议。

## 2. 目标用户

- 财商学习者、桌游爱好者。
- 1-6 人本地同屏游玩（热座模式），支持 AI 对手。
- 设备：桌面端浏览器为主，兼顾平板横屏。

## 3. 术语表

| 术语 | 说明 |
|------|------|
| 原始积累阶段（Rat Race） | 游戏第一阶段，玩家通过工作、投资积累被动收入，目标是被动收入 ≥ 总支出 |
| 资本加速阶段（Fast Track） | 玩家跳出原始积累后的第二阶段，通过大额投资实现购买梦想 |
| 月现金流 | 月收入 - 月支出 |
| 被动收入 | 来自资产（房产、股票、企业等）的收入 |
| 意外支出（Doodad） | 非必要消费/意外支出 |
| 市场风云 | 影响资产价格或经济环境的事件 |
| 财务自由 | 被动收入 ≥ 总支出的状态 |

## 4. 核心游戏规则

### 4.1 胜利条件

- **原始积累阶段**：玩家月被动收入 ≥ 月总支出时，可跳出原始积累，进入资本加速阶段。
- **资本加速阶段**：玩家在加速赛道上购买自己的梦想（Dream），即获得游戏胜利。

### 4.2 回合流程

1. 掷骰子前进相应格数。
2. 根据落到的格子触发对应事件：
   - **机会（绿色）**：抽取小机会/大机会卡片（股票、房产、企业等）。
   - **意外支出（红色）**：随机产生额外支出。
   - **发工资（黄色）**：获得月工资 + 当月现金流。
   - **市场风云（蓝色）**：影响所有玩家持有的资产价格或交易条件。
   - **孩子（青色）**：增加每月子女支出。
   - **慈善（金色）**：可选择捐赠 10% 总收入，下回合掷双骰。
   - **裁员（紫色）**：失去工作，停止获得工资，可用保险抵消。
3. 玩家可选择在回合中贷款、还贷、交易资产。
4. 结束回合，轮到下一位玩家。

### 4.3 财务模型

- 每月现金流 = 总收入（工资 + 被动收入） - 总支出。
- 工资由职业卡决定。
- 支出包含：税金、房贷、学生贷款、车贷、信用卡、其他支出、子女支出。
- 玩家现金 = 储蓄 + 现金流累积 + 资产买卖所得 - 支出 - 投资本金。

### 4.4 贷款规则

- 玩家可向银行申请贷款，贷款额度通常为总收入的 10 倍或固定上限。
- 贷款增加每月还款支出（利息 + 本金）。
- 可随时提前还贷。

### 4.5 可选规则

- **保险**：避免裁员事件影响。
- **大家庭**：提高孩子数量上限。
- **抵押贷款**：使用更真实的月供计算。
- **速开**：起始储蓄 = 总收入，加快开局节奏。

## 5. 功能需求

### 5.1 首页（Home）
- FR-001：展示游戏名称、简介、开始游戏按钮。
- FR-002：提供游戏规则入口（跳转至规则页）。
- FR-003：点击"开始游戏"进入游戏设置页。
- FR-004：展示免责声明（教育模拟，不构成投资建议）。

### 5.2 游戏设置（Setup）
- FR-005：支持选择玩家人数（1-6 人）。
- FR-006：为每位玩家配置姓名、职业、颜色。
- FR-007：支持随机职业与随机颜色。
- FR-008：提供可选规则开关（保险、大家庭、抵押贷款、速开）。
- FR-009：校验至少 1 位有效玩家后进入游戏。

### 5.3 原始积累棋盘
- FR-010：显示 24 格环形棋盘，含机会、意外支出、发工资、市场风云、孩子、慈善、裁员等格子。
- FR-011：左侧显示当前玩家财务报表（收入、支出、现金流、储蓄、资产、负债）。
- FR-012：顶部显示当前玩家标识与"进入加速赛道"按钮（仅在满足条件时可用）。
- FR-013：底部提供"掷骰子"、"贷款"、"结束回合"操作。
- FR-014：玩家落点通过颜色棋子/token 标识。
- FR-015：根据落点格子触发对应事件。

### 5.4 机会卡片（Card）
- FR-016：抽到机会时弹出卡片详情。
- FR-017：卡片类型包括：股票、房地产、企业、其它投资。
- FR-018：玩家可选择买入、卖出或放弃。
- FR-019：交易后实时更新财务报表与现金。

### 5.5 资本加速赛道（Fast Track）
- FR-020：显示加速赛道，含被动收入日、机会、投资、意外支出、梦想等格子。
- FR-021：保留顶部玩家信息与返回按钮。
- FR-022：在梦想格显示当前玩家选择的梦想与价格。
- FR-023：玩家现金达到梦想价格时可购买并获胜。

### 5.6 游戏规则页（Rules）
- FR-024：左侧 Tab 导航（游戏简介、原始积累、加速赛道、卡牌类型）。
- FR-025：右侧内容区以折叠面板展示详细规则说明。
- FR-026：支持返回首页导航。
- FR-027：响应式布局，移动端 Tab 转为顶部横排。

### 5.7 胜利结算页（Victory）
- FR-028：展示获胜玩家信息与庆祝动效。
- FR-029：显示关键数据概览（游戏回合数、最终现金、被动收入、总资产价值）。
- FR-030：展示成就徽章（加速赛道达成者、投资达人、梦想实现家等）。
- FR-031：提供"再来一局"和"返回首页"操作入口。

### 5.8 银行操作弹窗（Bank Modal）
- FR-032：多 Tab 模式：资产、存款、贷款、还款。
- FR-033：存款 Tab：显示当前余额，支持金额输入与快捷按钮，年利率说明。
- FR-034：贷款 Tab：显示贷款总额，支持金额输入与快捷按钮，月息与月还款额计算。
- FR-035：还款 Tab：显示未还贷款与还款进度，支持金额输入与快捷按钮。
- FR-036：资产 Tab：分类显示股票、房产、企业，展示成本、市值、月现金流。
- FR-037：操作后实时更新玩家财务数据。

### 5.9 AI 导师（学习模式）
- FR-038：学习模式下提供 AI 导师分析。
- FR-039：基于游戏内模拟状态给出策略比较。
- FR-040：明确标注"模拟分析，非投资建议"。

### 5.10 通用功能
- FR-041：游戏状态本地持久化（localStorage），支持断点续玩。
- FR-042：提供"重新开始"与"回到首页"入口。
- FR-043：响应式布局，适配桌面与平板。
- FR-044：历史对局记录与数据分析。

## 7. 数据模型

### 7.1 玩家（Player）
```ts
interface Player {
  id: string;
  name: string;
  color: string;
  career: Career;
  // 财务
  salary: number;
  passiveIncome: number;
  totalIncome: number;
  expenses: Expenses;
  totalExpenses: number;
  cashFlow: number;
  cash: number;
  // 资产与负债
  assets: Asset[];
  liabilities: Liability[];
  // 棋盘位置
  ratRacePosition: number;
  fastTrackPosition: number;
  // 状态
  isUnemployed: boolean;
  hasInsurance: boolean;
  childrenCount: number;
}
```

### 7.2 职业卡（Career）
```ts
interface Career {
  id: string;
  name: string;
  salary: number;
  expenses: Expenses;
  startingCash: number;
  difficulty: 'easy' | 'medium' | 'hard';
  description: string;
}
```

### 7.3 机会卡（OpportunityCard）
```ts
interface OpportunityCard {
  id: string;
  size: 'small' | 'big';
  type: 'stock' | 'real_estate' | 'business' | 'other';
  title: string;
  description: string;
  cost: number;
  cashFlow: number;
  // 股票特有
  symbol?: string;
  action?: 'buy' | 'sell';
  maxQuantity?: number;
}
```

### 7.4 游戏状态（GameState）
```ts
interface GameState {
  players: Player[];
  currentPlayerIndex: number;
  phase: 'rat_race' | 'fast_track';
  config: GameConfig;
  deck: CardDeck;
}
```

## 10. 法律与合规要求

### 10.1 知识产权
- 所有游戏内容（卡牌、职业、梦想、文案）为原创。
- 股票代码和公司名称均为虚构，不对应任何真实上市公司。
- 图标使用 Lucide（ISC License）。
- 字体使用系统字体栈，不捆绑未授权字体。

### 10.2 金融免责
- 游戏明确标注为"教育/娱乐模拟"。
- 所有金融数据均为虚构。
- AI 功能仅提供游戏内策略比较，不构成投资建议。
- 不使用真实金融市场数据。

### 10.3 隐私
- 不收集用户个人信息。
- 所有游戏数据保存在用户本地浏览器。
- 不使用第三方分析工具。

## 11. 测试计划

### 11.1 单元测试
- 财务计算：现金流、贷款利息、资产买卖。
- 回合逻辑：掷骰移动、格子事件触发、玩家切换。
- 胜利条件：跳出原始积累、购买梦想。

### 11.2 集成测试
- 从首页到设置页到棋盘的完整流程。
- 机会卡片买入/卖出后财务报表更新。
- 游戏状态本地持久化与恢复。
- 市场风云多玩家轮询逻辑。
- 失业状态下的完整回合流程。

### 11.3 手动测试
- 多玩家热座切换是否正常。
- 响应式布局在桌面与平板上的表现。
- 边界情况：现金不足、失业、超额贷款。
- 骰子动画在单/双骰模式下均正常。

## 13. 风险与假设

- 假设玩家在本地同一设备上轮流操作，无需网络对战。
- 卡片与职业数据为静态配置，后续可扩展为动态加载。
- 所有金融数据为虚构模拟，不反映真实市场。
- AI 功能仅作为游戏内学习辅助，不提供真实投资建议。
