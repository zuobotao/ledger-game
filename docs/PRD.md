> 版本：v1.0  
> 日期：2026-08-02  
> 状态：设计原型已通过质量门，进入需求梳理阶段

---

## 1. 项目背景与目标

### 1.1 背景
复刻罗伯特·清崎（Robert Kiyosaki）经典财商桌游《Cashflow 101》的核心玩法，让玩家在浏览器中体验“走出老鼠赛跑，进入快车道”的财务成长过程。

### 1.2 目标
- 提供一个可本地多人（热座）游玩的网页版 Cashflow 101。
- 完整还原老鼠赛跑（Rat Race）与快车道（Fast Track）两个核心阶段。
- 通过财务报表、机会卡片、市场风云等机制，帮助玩家理解资产、负债、现金流的关系。

---

## 2. 目标用户

- 财商学习者、桌游爱好者。
- 2-6 人本地同屏游玩（热座模式）。
- 设备：桌面端浏览器为主，兼顾平板横屏。

---

## 3. 术语表

| 术语 | 说明 |
|------|------|
| 老鼠赛跑 | 游戏第一阶段，玩家通过工作、投资积累被动收入，目标是被动收入 ≥ 总支出 |
| 快车道 | 玩家跳出老鼠赛跑后的第二阶段，通过大额投资实现购买梦想 |
| 现金流 | 月收入 - 月支出 |
| 被动收入 | 来自资产（房产、股票、企业等）的收入 |
|  doodad | 非必要消费/意外支出 |
| 市场风云 | 影响资产价格或经济环境的事件 |

## 4. 核心游戏规则

### 4.1 胜利条件
- **老鼠赛跑阶段**：玩家月被动收入 ≥ 月总支出时，可跳出老鼠赛跑，进入快车道。
- **快车道阶段**：玩家在快车道上购买自己的梦想（Dream），即获得游戏胜利。

### 4.2 回合流程
1. 掷骰子前进相应格数。
2. 根据落到的格子触发对应事件：
   - **机会（绿色）**：抽取小机会/大机会卡片（股票、房产、企业等）。
   - **负债（红色）**：随机产生 doodad 支出。
   - **发工资（黄色）**：获得月工资 + 当月现金流。
   - **市场风云（蓝色）**：影响所有玩家持有的资产价格或交易条件。
   - **孩子（青色）**：增加每月子女支出。
   - **慈善（金色）**：可选择捐赠 10% 总收入，下回合掷双骰。
   - **裁员（紫色）**：失去工作，停止获得工资，可用保险抵消。
3. 玩家可选择在回合中贷款、还贷、交易资产。
4. 结束回合，轮到下一位玩家。

### 4.3 财务模型
- 每月现金流 = 总收入（工资 + 被动收入） - 总支出。
- 工资由职业卡决定。
- 支出包含：税金、房贷、学生贷款、车贷、信用卡、其他支出、子女支出。
- 玩家现金 = 储蓄 + 现金流累积 + 资产买卖所得 - 支出 - 投资本金。

### 4.4 贷款规则
- 玩家可向银行申请贷款，贷款额度通常为总收入的 10 倍或固定上限。
- 贷款增加每月还款支出（利息 + 本金）。
- 可随时提前还贷。

### 4.5 可选规则
- **保险**：避免裁员事件影响。
- **大家庭**：提高孩子数量上限。
- **抵押贷款**：使用更真实的月供计算。
- **速开**：起始储蓄 = 总收入，加快开局节奏。

## 5. 功能需求

### 5.1 首页（Home）
- FR-001：展示游戏名称、简介、开始游戏按钮。
- FR-002：提供游戏规则入口（原型阶段为占位，可后续扩展）。
- FR-003：点击“开始游戏”进入游戏设置页。

### 5.2 游戏设置（Setup）
- FR-004：支持选择玩家人数（1-6 人）。
- FR-005：为每位玩家配置姓名、职业、颜色。
- FR-006：支持随机职业与随机颜色。
- FR-007：提供可选规则开关（保险、大家庭、抵押贷款、速开）。
- FR-008：校验至少 1 位有效玩家后进入游戏。

### 5.3 老鼠赛跑棋盘（Rat Race）
- FR-009：显示 24 格环形棋盘，含机会、负债、发工资、市场风云、孩子、慈善、裁员等格子。
- FR-010：左侧显示当前玩家财务报表（收入、支出、现金流、储蓄、资产、负债）。
- FR-011：顶部显示当前玩家标识与“进入快车道”按钮（仅在满足条件时可用）。
- FR-012：底部提供“掷骰子”、“贷款”、“结束回合”操作。
- FR-013：玩家落点通过颜色棋子/token 标识。
- FR-014：根据落点格子触发对应事件。

### 5.4 机会卡片（Card）
- FR-015：抽到机会时弹出卡片详情。
- FR-016：卡片类型包括：股票、房地产、企业、其它投资。
- FR-017：玩家可选择买入、卖出或放弃。
- FR-018：交易后实时更新财务报表与现金。

### 5.5 快车道（Fast Track）
- FR-019：显示快车道线性轨道，含现金流日、机会、投资、doodad、梦想等格子。
- FR-020：保留顶部玩家信息与返回按钮。
- FR-021：在梦想格显示当前玩家选择的梦想与价格。
- FR-022：玩家现金达到梦想价格时可购买并获胜。

### 5.6 通用功能
- FR-023：游戏状态本地持久化（localStorage），支持断点续玩。
- FR-024：提供“重新开始”与“回到首页”入口。
- FR-025：响应式布局，适配桌面与平板。

---

## 6. 非功能需求

- NFR-001：前端框架使用 Vue 3 + Vite。
- NFR-002：状态管理使用 Pinia。
- NFR-003：样式使用 Tailwind CSS，遵循苹果设计系统（原型已验证）。
- NFR-004：图标使用 Lucide。
- NFR-005：单页应用（SPA），路由使用 Vue Router。
- NFR-006：无后端依赖，数据存储在浏览器本地。
- NFR-007：代码需通过 ESLint + Prettier 检查。

## 7. 数据模型

### 7.1 玩家（Player）
```ts
interface Player {
  id: string;
  name: string;
  color: string;
  career: Career;
  // 财务
  salary: number;
  passiveIncome: number;
  totalIncome: number;
  expenses: Expenses;
  totalExpenses: number;
  cashFlow: number;
  cash: number;
  // 资产与负债
  assets: Asset[];
  liabilities: Liability[];
  // 棋盘位置
  ratRacePosition: number;
  fastTrackPosition: number;
  // 状态
  isUnemployed: boolean;
  hasInsurance: boolean;
  childrenCount: number;
}
```

### 7.2 职业卡（Career）
```ts
interface Career {
  id: string;
  name: string;
  salary: number;
  expenses: Expenses;
  startingCash: number;
}
```

### 7.3 机会卡（OpportunityCard）
```ts
interface OpportunityCard {
  id: string;
  type: 'small' | 'big' | 'stock' | 'real_estate' | 'business';
  title: string;
  description: string;
  cost: number;
  cashFlow: number;
  // 股票特有
  symbol?: string;
  priceRange?: [number, number];
}
```

### 7.4 游戏状态（GameState）
```ts
interface GameState {
  players: Player[];
  currentPlayerIndex: number;
  phase: 'rat_race' | 'fast_track';
  config: GameConfig;
  deck: Deck;
  marketEvents: MarketEvent[];
}
```

## 10. 测试计划

### 10.1 单元测试
- 财务计算：现金流、贷款利息、资产买卖。
- 回合逻辑：掷骰移动、格子事件触发、玩家切换。
- 胜利条件：跳出老鼠赛跑、购买梦想。

### 10.2 集成测试
- 从首页到设置页到棋盘的完整流程。
- 机会卡片买入/卖出后财务报表更新。
- 游戏状态本地持久化与恢复。

### 10.3 手动测试
- 多玩家热座切换是否正常。
- 响应式布局在桌面与平板上的表现。
- 边界情况：现金不足、失业、超额贷款。

## 12. 风险与假设

- 假设玩家在本地同一设备上轮流操作，无需网络对战。
- 卡片与职业数据为静态配置，后续可扩展为动态加载。
- 原型阶段已确定视觉风格，开发阶段需保持与原型一致。
