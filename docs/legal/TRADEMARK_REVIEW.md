# Trademark Review — Ledger

**Brand:** Ledger
**Search Date:** 2026-09-04
**Search Scope:** Web, GitHub, Major trademark databases (USPTO, EUIPO)
**Risk Level:** MEDIUM
**Decision:** KEEP — with clear differentiation strategy

---

## 1. Existing "Ledger" Brands

### 1.1 Ledger (Crypto Hardware Wallet)
- **Company:** Ledger SAS (Paris, France)
- **Industry:** Cryptocurrency hardware wallets, fintech security
- **Products:** Ledger Nano S, Ledger Nano X, Ledger Stax
- **Website:** ledger.com
- **Trademark status:** Registered in multiple jurisdictions for "computer hardware, software, and financial services related to cryptocurrency"
- **Relevance:** HIGH — both use "Ledger" in a financial/technology context

**Analysis:**
Ledger SAS is the most well-known "Ledger" brand in fintech. They specialize in cryptocurrency hardware wallets. While both involve "finance," the products are significantly different:
- They sell physical hardware security devices for crypto storage
- Ledger (this project) is a browser-based educational financial simulation game

The key question is **likelihood of consumer confusion**. Given that:
1. The product categories differ (hardware wallets vs. educational games)
2. This project is open-source and non-commercial
3. The visual identity and product positioning are distinct

...the risk is **MEDIUM** rather than HIGH. However, the project should proactively differentiate itself to minimize confusion.

### 1.2 Other "Ledger" Brands
- **LedgerX** (now part of FTX estate): Bitcoin options exchange — distinct name, defunct
- **General Ledger** / **Ledger** in accounting context: Generic term, widely used
- **Various "Ledger" software tools:** Many tools use "ledger" in the accounting sense

---

## 2. Risk Factors

### Factors increasing risk:
1. **Same general industry:** Both relate to finance/technology
2. **Well-known primary brand:** Ledger SAS is the dominant "Ledger" brand in fintech
3. **Domain similarity:** ledger.com is taken by the crypto wallet company

### Factors decreasing risk:
1. **Different product categories:** Hardware wallets ≠ educational games
2. **Non-commercial:** This project is open-source, free, and not monetized
3. **Distinct positioning:** Financial simulation game ≠ crypto security hardware
4. **Generic word:** "Ledger" is a common English word with accounting meaning
5. **No endorsement claims:** Project does not claim any affiliation with Ledger SAS

---

## 3. Differentiation Strategy (Must Implement)

To keep the "Ledger" name while minimizing trademark risk, implement ALL of the following:

### 3.1 Brand Positioning
- [x] Always use full description: "Ledger — Financial Decision Simulation Game"
- [x] Never use just "Ledger" in isolation on key brand surfaces
- [x] Clearly distinguish from financial products, services, and crypto wallets
- [x] Add "Independent project" statement in README and website footer

### 3.2 Visual Identity
- [ ] Original logo (must NOT resemble Ledger SAS branding)
- [ ] Distinct color scheme (avoid Ledger SAS's black/gold branding)
- [x] No diamond or hardware wallet imagery

### 3.3 Domain & Repository
- [ ] Avoid `ledger.com` / `ledger.io` style domains
- [ ] Use a clearly game-oriented subdomain or repository name
- [x] GitHub repo: `ledger-game` (already distinguishes as a game)

### 3.4 Disclaimer
- [x] "Ledger is an independent open-source financial simulation game. It is not affiliated with, endorsed by, or sponsored by any financial institution, cryptocurrency company, or hardware wallet provider."

---

## 4. Trademark Classes

Relevant USPTO classes:
- **Class 9:** Computer software, video games — Ledger SAS may have registrations here for wallet software
- **Class 36:** Financial services — Ledger SAS likely has registrations here
- **Class 41:** Education, entertainment, gaming — Lower conflict risk

This project primarily falls under **Class 41** (educational/entertainment software) and **Class 9** (video game software), which provides some separation from Ledger SAS's core financial services registrations.

---

## 5. Recommendation

**Decision: KEEP the name "Ledger" with MEDIUM risk level.**

Conditions for keeping the name:
1. ✅ Always position as "financial decision simulation game" — never as a financial product or service
2. ✅ Maintain original visual identity (no similarity to Ledger SAS branding)
3. ✅ Add clear independent project statement on all public-facing surfaces
4. ✅ Do not use "Ledger" in ways that could imply financial services or crypto wallet functionality
5. ⚠️ If the project ever becomes commercial (paid, subscription, etc.), re-evaluate trademark risk immediately

**If risk escalates:** Consider alternative names like "LedgerSim", "FinLedger", or a fully distinct brand name.
