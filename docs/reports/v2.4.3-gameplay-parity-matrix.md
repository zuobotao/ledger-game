# v2.4.3 — Single / Multiplayer Gameplay Parity Matrix

> Phase 0 交付物（v2.4.3 执行文档 §3）
> 基线：`main` @ `bea81fa`（v2.4.1+ 多人连发版本）
> 目标：明确哪些差异是「业务规则允许」，哪些只是「多人页没实现」。

## 结论摘要

| 结论 | 数量 |
|---|---|
| ✅ 已共享（复用同一组件） | 2 |
| ⚠️ 业务规则允许的差异 | 3 |
| ❌ 多人页未实现（可共享） | 16 |
| 🔴 多人页缺失导致软锁 / 规则断链（P0） | 5 |

**核心问题**：MultiplayerGameView（371 行）是一个「简化版独立玩法页」，不是共享 UI 的薄壳。
对比 RatRaceView（1825 行）/ FastTrackView（1406 行），多人页缺失绝大部分玩法交互，
且存在 5 处会让对局卡死或规则断链的 P0 缺口（见 §P0）。

## P0 缺口（软锁 / 规则断链）

以下 5 处是必须在本版本修复的硬伤，任一存在都可能导致多人对局无法完成：

| # | 缺口 | 证据 | 影响 |
|---|---|---|---|
| P0-A | `fast_track_stock_trading` pending 时多人页无按钮 | `deriveAllowedActions` 返回 `['fast_track_stock_trading']`；MultiplayerGameView `actionButtons` 无此 key | 玩家回合永久卡死（软锁），对局不可继续 |
| P0-B | `skip_stock_sell` 无按钮 | `allowedActions` 返回 `['sell_opportunity','skip_stock_sell']`；多人页只有 `sell_opportunity`（且数量恒 1） | 无法放弃股票卖出机会；被迫卖出 1 股 |
| P0-C | 多人玩家无法进入 FastTrack | `send_to_fast_track` 不在 `deriveAllowedActions`；多人页无 watch/按钮；AI 路径（store L2714）仅限 AI | 多人局永远停在 Rat Race，Capital/梦想/胜利不可达 |
| P0-D | 市场事件无法卖出资产 | `dismissMarket()` 只发 `sellAssetIds: []`；多人页无卖出面板 | 市场卡等于纯文本，策略空间被砍 |
| P0-E | `fast_track_opportunity` 服务端数量恒 1 | `actionMap` L183 `buyOpportunity(1)`；`fast_track_opportunity` 协议无 quantity 字段 | 资本阶段机会无法选量 |

## 服务端命令能力（用于判断差异归属）

`server/game/actionMap.ts` 已支持（多人页未用或未正确用）：

```
roll_dice / end_turn / buy_opportunity(qty) / decline_opportunity
handle_charity(accepted) / handle_market(sellAssetIds) / handle_doodad / handle_story
take_bank_loan(amount) / repay_bank_loan(liabilityId,amount)
deposit_savings(amount) / withdraw_savings(amount)
sell_opportunity(assetId,qty,price) / skip_stock_sell
declare_bankruptcy / send_to_fast_track*（*存在但不可达）
fast_track_dream(accepted) / fast_track_opportunity(accepted,qty=1) / fast_track_stock_trading(symbol,qty,isBuy)
```

服务端缺失：

```
buy_insurance（多人保险完全不可用 → P1 补充）
send_to_fast_track 未加入 deriveAllowedActions（P0-C）
```

## 业务规则允许的差异

1. **孩子展示强度**：单机 Header 有子女数徽章；多人列表展示孩子数即可，属展示层级差异。
2. **胜利展示**：多人需要额外展示网络/房间信息（房间码、离开、等待玩家），属多人语境必要信息。
3. **isMyTurn / 网络状态 / 房间信息**：共享 UI 明确允许差异（v2.4.3 §31）。
