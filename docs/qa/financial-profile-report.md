# 财务行为画像 QA

## 覆盖范围

结束总结（胜利、破产、退休）现在包含“本局行为画像”折叠段落，展示四个稳定维度：现金流规划、风险偏好、流动性纪律、机会选择。每个维度显示等级、0–100 分、简短解释，以及从本局交易和卡牌历史提取的证据。

画像使用 `playerId` 过滤交易和卡牌记录，避免把其他玩家行为混入报告。没有历史记录时仍会显示四个维度，并以 0 次操作作为证据；因此旧存档也能安全渲染。

## 自动验证

- `npm run type-check`
- `npx vitest run test/unit/financial-profile.spec.ts`

单测覆盖四维输出、分数范围、机会证据、心理诊断免责声明，以及跨玩家数据隔离。

## 手工检查

1. 以胜利、破产和退休结算各完成一次对局，确认结束总结默认打开“本局行为画像”。
2. 分别进行存款、取款、贷款、还款、买入、卖出、慈善和机会牌接受/放弃操作，确认对应证据计数更新。
3. 在移动宽度下确认画像卡片变为单列，长文案不会挤压等级或分数。
4. 关闭画像段落后，其他总结段落仍可独立展开。
