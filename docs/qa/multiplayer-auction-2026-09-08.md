# 多人机会竞价 QA

## 规则

- 当前玩家遇到可购买机会时，多人局额外显示“多人竞价”。股票卖出、拆分/合股等非购买机会不进入竞价。
- 其他玩家按现金安全垫、机会月现金流和负债压力计算一次密封报价，最高报价者获得资产。
- 成交款进入机会发现者账户，竞得者按成交价支付，竞价完成后回合继续，不等待其他客户端逐个响应。
- 没有玩家能在保留应急现金后参与时，机会安全关闭并给出明确提示。

## 验证

```sh
npx vitest run test/unit/asset.spec.ts test/unit/gameplay-single-adapter.spec.ts test/unit/gameplay-multiplayer-adapter.spec.ts test/unit/v24-headless.spec.ts
```

结果：4 个测试文件、30 个测试通过；覆盖成交、无人竞价、单机适配器和无头多人宿主兼容性。

## 教学目标

竞价把“有机会但缺现金”和“有现金但未遇到机会”连接起来，同时明确展示安全垫约束，避免把多人玩法变成无成本抢购。
