# Ledger 全流程验收矩阵（2026-09-08）

本文记录当前版本的 PC、移动端和多人房间验收入口，作为后续每次发布的回归清单。状态只表示已有证据，不代表未执行项已通过。

## 设备维度

### 手机

- 已验证：资产购买说明、购买信息不遮挡、侧栏滚动、棋盘格中文说明、落点文案、顶部被动收入。
- 已验证：随机 Bot 长局 50 回合内不再卡在市场事件，原有回合 39/41 卡死点已消失。
- 待验证：真实设备横屏完整棋盘、系统返回键、浏览器刷新后房间恢复、完整全分支点击。

### PC

- 已验证：生产构建、核心单元测试、桌面布局代码路径。
- 待验证：真实浏览器逐页面点击、窗口缩放、桌面多人跨窗口同步、资本页面完整分支。

### 房间

- 已验证：协议、加入、断线重连、刷新恢复和多人反馈标识的单元路径。
- 待验证：真实 PC/手机混玩、两窗口继续游戏提示、房主/非房主全流程点击。

## 发布门槛

1. `npm run type-check`
2. `npm run build`
3. 相关 Vitest 定向测试
4. 手机/PC/房间 Playwright 场景；若运行环境阻断浏览器，必须记录原因，不得标记为通过。
5. 每个功能提交代码测试 commit，再提交 QA 文档 commit。

## 当前已知限制

- 随机 Bot 仍可能触发测试回合上限，尚未证明所有策略都能自然进入结束页。
- 历史记录目前支持本地保存和摘要回顾，确定性逐步回放仍待实现。
- 邀请制账户、云端同步和跨设备存档尚未实现。
