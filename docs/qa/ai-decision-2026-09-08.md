# AI 决策迭代 QA

## 变更

- AI 机会决策增加综合评分：现金流缺口、机会回报、应急现金、负债压力和股票风险共同影响买入判断。
- 三档难度仍保留差异：简单更重视现金安全，均衡保持三个月储备，困难仅在高回报时允许更激进。
- 购买数量会受到应急现金安全垫约束，避免 AI 把现金一次性买空。
- 评分结果保留 `reason` 字段，便于后续在复盘报告中解释“为什么买/不买”。

## 验证

```sh
npx vitest run test/unit/ai-decision.spec.ts test/unit/ai-policies.spec.ts
```
